# 빈칸 MVP

취업 준비생이 복잡한 계획을 관리하기보다 **지금 해야 할 일정 하나**를 바로 확인하도록 만든 무료 일정관리 웹앱입니다.

## 현재 기능

- 자연스러운 한국어 한 줄 입력으로 일정 등록
  - 예: `내일 오후 3시 A기업 자소서 1시간`
  - 예: `금요일까지 포트폴리오 제출`
- 날짜·시간·예상 소요시간·취준 카테고리 규칙 기반 추출
- 동일하거나 겹치는 일정 등록 허용 + 눈에 띄는 경고
- 현재 시각을 기준으로 진행 중·놓친·다음·시간 미정 일정 추천
- 완료, 완료 취소, 30분 미루기, 내일로 이동, 삭제 및 삭제 취소
- 날짜별 일정과 완료 현황
- ChatGPT 사용자별 D1 데이터 분리 저장
- 모바일 반응형 화면

규칙 기반 분석이므로 외부 AI API 비용이 들지 않습니다. 25명 규모의 텍스트 일정은 Cloudflare 무료 한도 안에서 충분히 운영하도록 설계했습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```powershell
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 로컬에서는 `local-demo-user` 계정으로 동작합니다.

## 확인 명령

```powershell
npm run lint
npm test
npm run db:generate
```

## 저장 구조

- 화면: React 19 + vinext
- 저장: Cloudflare D1(SQLite 호환)
- 데이터 분리: 배포 환경의 `oai-authenticated-user-id`
- 설정: `.openai/hosting.json`의 `DB` 바인딩
- 스키마: `db/schema.ts`
- API: `app/api/events/route.ts`

서버는 최초 요청에도 테이블을 안전하게 확인하고, 배포 시에는 `drizzle/`의 SQL 마이그레이션을 적용할 수 있습니다.
